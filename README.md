## 🚀 Quick Start

### Prerequisites
- **Node.js** (v18 or higher)
- **npm** (comes with Node.js)
- **Git**

### Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/swarajreddy10/swarajreddy10.github.io.git
   cd swarajreddy10.github.io
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```
   🌐 Open [http://localhost:3000](http://localhost:3000) to view the portfolio

### Available Scripts

```bash
# Development with Turbopack
npm run dev

# Build and export for production
npm run build

# Export static files
npm run export

# Start production server
npm start

# Lint code
npm run lint

# Deploy to GitHub Pages
npm run deploy
```

## 🚀 Deployment

This portfolio is configured for **GitHub Pages** deployment with automatic static export.

### Deploy to GitHub Pages
```bash
npm run deploy
```

### Deployment Configuration
- **Output**: Static export (`output: "export"` in `next.config.mjs`)
- **Images**: Unoptimized for static hosting
- **Base Path**: Configured for root domain deployment
- **Jekyll**: Disabled with `.nojekyll` file
